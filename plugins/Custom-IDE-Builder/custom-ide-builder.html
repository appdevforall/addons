Custom IDE Builder

Custom IDE Builder makes a copy of the Code on the Go installed on this device, with the plugins and templates you choose bundled inside it, and signs the copy with your own key. Use it to hand out a version of Code on the Go that arrives with the add-ons a class, a team or a community needs already in place.

Read this before you install a copy. The copy is signed with your key, not ours, so Android treats it as a different app. It installs only after Code on the Go has been uninstalled, and uninstalling erases the projects stored in the app's data. Copy your projects out first.

What you need

  • A keystore file in PKCS12 (.p12) or BKS format, such as one made by Keystore Generator. A Java KeyStore (.jks) file made by keytool must be converted first, on a computer: keytool -importkeystore -srckeystore old.jks -srcstoretype JKS -destkeystore new.p12 -deststoretype PKCS12.
  • The add-ons: .cgp plugin files and .cgt template files from this device, or downloaded from the add-ons website.
  • A folder to save the finished APK in, and free space for about twice the size of Code on the Go.

How to use it

  1. Open Custom IDE Builder from the main menu.
  2. Add-ons. Tap Add from this device to pick several files at once. Tap Add from the website to choose from the add-ons that work with this version of Code on the Go. Nothing is downloaded until you confirm; the downloads come from addons.appdevforall.org and each one is checked against the size and SHA-256 the website publishes.
  3. Signing key. Choose the keystore file, type the store password and tap Read keys, then pick the key. Leave the key password blank if it is the same as the store password.
  4. Output folder. Choose it once; it is remembered.
  5. Tap Build APK. The file is saved as <app name>-<version>-custom.apk.

Good to know

  • Use the same key every time. A device that has a build signed with one key cannot update to a build signed with another without being uninstalled first.
  • Passwords are never saved. They are used for the build in front of you and cleared when you leave the screen.
  • Each plugin must have its own plugin ID and each template its own file name; the builder says which add-ons clash. core.cgt is never bundled, because Code on the Go installs it itself.
  • Nothing chosen makes a copy that carries no add-ons.
  • The copy is built from the APK of this installation. It does not work if Code on the Go was installed as split APKs; the screen says so.
  • The app is copied without being recompressed, so building takes about as long as copying the file, plus the time to sign it.
