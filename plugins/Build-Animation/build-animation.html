Build Animation

An animated toolbar icon that shows when Gradle is working

1. Executive Overview

Build Animation adds a small icon to the end of the editor toolbar that shows whether Gradle is working. A wrench rocks during a build or project sync, then a tick or a cross shows the result for a few seconds. When nothing is building, the icon is a greyed-out wrench.

It is aimed at learners: a build that takes a minute on a phone is easier to wait for when something on screen says it is still going. It needs no permissions, reads no files and uses no network.

Tapping the icon while it is active shows the current status as a short message.

3. Technical Architecture

  • BuildAnimationPlugin implements IPlugin, UIExtension, DocumentationExtension and BuildStatusListener. Build callbacks arrive on the main thread.
  • Its single ToolbarAction uses iconProvider to pick the drawable for the current state and isEnabledProvider to grey it out when idle. Each state change calls IdeUIService.refreshToolbarActions(), and the host starts any animated drawable it is given. The plugin draws no view of its own.
  • BuildAnimationState is a small state machine with no Android dependencies, so it is unit-tested on the JVM. A new build that starts while a result is still showing cancels that result's pending return to idle.
  • The icon is never hidden, only greyed out. The toolbar is end-aligned, so adding or removing an icon would shift every built-in button, and Stop would move out from under the finger that just tapped Run.
  • The result shows for 5 seconds, longer than the IDE's own "Build successful" message, which briefly covers the toolbar.
  • On activation it asks IdeBuildService.isBuildInProgress(), so enabling the plugin mid-build shows the animation straight away. Deactivating or disposing the plugin removes its build listener and cancels any pending timer.

4. Usage

  1. Install the plugin from the Plugin Manager and restart Code on the Go when asked.
  2. Open a project. A greyed-out wrench appears at the end of the editor toolbar.
  3. Run, build or sync. The wrench rocks until Gradle finishes, then shows a tick or a cross.
  4. Long-press the icon for help, including a link to the full in-app guide.

To build the plugin from source:

cd plugins/Build-Animation
../../gradlew assemblePlugin

The .cgp lands in build/plugin/.

5. Key Benefits

  • See build status at a glance without opening the build output.
  • Never moves your buttons. The icon keeps its slot, so taps land where you expect.
  • No permissions, no network. It only listens for build events.
  • Colour-independent. The result is a shape (tick or cross), and the toolbar tints it to match the light or dark theme.
  • Easy to re-skin. The animations are vector drawables in src/main/res/drawable/.

6. Limits

  • Sync animates too. The IDE reports a project sync to plugins as a build start.
  • Quick Build does not animate. Quick Build is not reported to plugins yet.
  • Activity, not progress. The plugin API carries no progress, so the animation is indeterminate.
  • Supports Code on the Go 26.29 through 26.99. 26.29 is the first release with dynamic toolbar icons.
