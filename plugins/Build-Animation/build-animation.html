Build Animation

An animated toolbar icon that shows when Gradle is working

1. Overview

Build Animation adds a small icon to the end of the editor toolbar while Gradle runs. A wrench rocks during the build, then a tick or a cross shows the result for a few seconds. When nothing is building the icon is a greyed-out wrench.

It needs no permissions: it only listens for build events and contributes a toolbar icon.

2. Behaviour

Build eventCallbackIcon
Build or sync startsonBuildStarted()Rocking wrench, avd_build_running (loops)
Build succeedsonBuildFinished()Tick draws itself, avd_build_succeeded
Build fails or is cancelledonBuildFailed(error)Cross draws and shakes, avd_build_failed
5 seconds after a result—Greyed-out wrench

Tapping the icon shows the current status as a toast.

3. How it works

  • BuildAnimationPlugin implements IPlugin, UIExtension, DocumentationExtension and BuildStatusListener.
  • Its single ToolbarAction uses iconProvider to pick the drawable for the current state and isEnabledProvider to grey it out when idle. Each state change calls IdeUIService.refreshToolbarActions(), and the host starts any animated drawable it is given.
  • BuildAnimationState is a small state machine with no Android dependencies, so it is unit-tested on the JVM. A new build that starts while a result is still showing cancels that result's pending return to idle.
  • The icon is never hidden, only greyed out. The toolbar is end-aligned, so adding or removing an icon would shift every built-in button, and Stop would move out from under the finger that just tapped Run.
  • On activation it asks IdeBuildService.isBuildInProgress(), so enabling the plugin mid-build shows the animation straight away.

4. Limits

  • Sync animates too. The IDE reports a project sync to plugins as a build start.
  • Quick Build does not animate. Quick Build is not reported to plugins yet.
  • Activity, not progress. The plugin API carries no progress, so the animation is indeterminate.
  • Requires Code on the Go 26.29 or later, the first release with dynamic toolbar icons.

5. Building

cd plugins/Build-Animation
../../gradlew assemblePlugin

The .cgp lands in build/plugin/ and installs from the IDE's plugin manager.
