Build Animation

Build Animation puts a small animated icon at the end of the editor toolbar while Gradle is working, so you can see at a glance that a build is running and how it ended.

What you see

WhenThe icon
Nothing is buildingA greyed-out wrench. It stays in place so the other toolbar buttons never move.
A build or project sync is runningA wrench rocks back and forth.
The build finishedA tick draws itself, then the icon greys out again after a few seconds.
The build failed or was cancelledA cross draws itself and shakes, then the icon greys out again after a few seconds.

Tap the icon to see the current status as a short message.

Good to know

  • Project sync animates too. Opening or syncing a project runs Gradle, and the IDE reports that to plugins the same way as a build.
  • Quick Build does not animate. The IDE does not report Quick Build to plugins yet.
  • The animation shows activity, not progress. It cannot tell how far along a build is.
  • Turning animations off works. If you turn off animations in Android's accessibility or developer settings, the icon still appears but stays still.
  • If your toolbar is full, the icon may be scrolled out of view at the end.

Permissions

None. The plugin only listens for build events and adds a toolbar icon. It does not read your files or use the network.
