SQLite Explorer

Browse and query the SQLite databases of the app you are building, while its debug build runs on this phone. SQLite Explorer only reads: nothing it does changes the app's data.

What you need

  • The app's project open in Code on the Go's editor.
  • The project's gradle.properties has cogo.sqliteDebugger=true. New projects from a template that has a database include it. Code on the Go's build then adds its database debugger to the app's debug build.
  • The app's debug build running. When it starts, it tells Code on the Go the port and token of its debugger.

Using it

  • Connect finds the app. A project with several apps asks which one, and remembers the choice.
  • Databases lists the databases the app has open. Tap one to open it.
  • Tables and views: tap one to see its rows, 100 at a time, with Previous and Next. SQL shows the statement that created it.
  • Query runs one SQL statement you type, and Query plan shows how SQLite would run it.
  • Stats shows the database's size and each table's row count. Quick and Full integrity check look for corruption; the full check also compares indexes with their tables and takes longer.
  • Tap a value to see all of it. Under each column name is its declared type. NULL is in italics.
  • Long-press anything on the screen for help about it.

Limits

  • Read-only. The app's debugger refuses any statement that writes, and more than one statement at a time.
  • Open databases only. A database the app has not opened, or opened through Android's own SQLite, is shown as not available. Reading it from a second copy of SQLite could corrupt it.
  • Long values are cut. The debugger sends at most 4 KiB of a text value and 1 KiB of a BLOB, and about 4 MiB per page. A cut value ends in an ellipsis.
  • Pages can shift. Each page runs the statement again, so a later page can differ if the data changed.
  • The app's own functions are missing. Functions the app adds to its own connections, such as stored JavaScript functions, do not exist in the debugger's connections.
  • A restarted app has a new port and token. If the app was stopped or restarted, choose Reconnect.
  • Slow statements stop. On a database that is not in WAL mode, a statement is stopped after about 1.5 s, so the app's own writes are not held up.

Privacy

SQLite Explorer talks only to the app on this phone, at 127.0.0.1. It sends nothing off the device and stores only which app you chose last.
