1. Overview

Go Tools adds Go as a project type in Code on the Go. While a Go project is open, the toolbar swaps its Gradle actions for Go ones; every other project is left untouched. The Go toolchain ships inside the plugin, so Go programs build, run, and test with no network connection.

Run app builds your program and then runs the result, so Cancel stops your program itself, not just the compiler.

2. Editing

  • Syntax highlighting for .go files, from a tree-sitter grammar.
  • Completion, diagnostics, go to definition, references, signature help, and formatting from gopls.

3. Commands

CommandWhat it doesOffline
Run appBuilds the main package in the project root, then runs itYes
Run current fileBuilds and runs the .go file open in the editorYes
Run testsRuns go test ./...Yes
Tidy modulesRuns go mod tidyNo: modules come from the Go module proxy

4. Templates

TemplateWhat you get
Go StarterA minimal module with a function and a table-driven test
Go HTTP ServerA net/http server with an HTML page, a JSON route, timeouts, and graceful shutdown

Both templates use only the standard library, so they build and run without downloading anything.

5. What is bundled

  • Go 1.27 and gopls 0.23, Termux builds that work with projects on the device's shared storage.

On the first launch the plugin unpacks the toolchain once into its private directory. Devices with a 32-bit ARM processor download the same pinned, checksummed packages once instead.
