JVM Tools

Run Java and Kotlin programs on the device, straight from the editor toolbar.

JVM Tools adds a project template and two toolbar commands. The commands appear only while a JVM project is open; in an Android project the toolbar is left alone. Because Gradle plays no part in a JVM project, the Gradle actions (Quick Run, Quick Build, Sync, Debug, Run Tasks, Launch App) are hidden while you work in one.

A project counts as JVM when it has no Gradle build file (build.gradle, build.gradle.kts, settings.gradle, or settings.gradle.kts) and holds at least one .java or .kt file within four folders of its root.

The commands

Run

Compiles every .java and .kt file in the project, then starts the main class chosen in Run configuration with its program arguments. Folders named build and folders whose names start with a dot are skipped. Kotlin is compiled first, so Java and Kotlin classes can use each other.

When no main class has been chosen, Run starts the main class of the file open in the editor, or else the first main class in alphabetical order.

Compiler errors and the program's output stream into Build Output. While the program runs, the button becomes Cancel Run; tap it to stop the program. A run is stopped after 30 minutes. Unsaved changes in open Java and Kotlin files are saved before compiling.

Run configuration

Chooses which main class Run starts and the program arguments it passes. The list holds every class with a main method:

  • a Java class with public static void main(String[] args)
  • a Kotlin file with a top-level fun main(), which runs as FileNameKt
  • a Kotlin object or companion object with a @JvmStatic main

Program arguments are split on spaces. Wrap an argument in single or double quotes to keep its spaces, for example --name "Ada Lovelace". The choice is saved for each project.

The project template

Java/Kotlin Program on the New Project screen creates a program in src/: a Main class that prints a greeting built by a Greeter class. Choose Java or Kotlin when you create it, then tap Run.

What it cannot do

  • The program cannot read keyboard input: Scanner and readLine() see the end of input. Pass values as program arguments instead.
  • Libraries are not downloaded. A program can use the Java class library and, for Kotlin, the Kotlin standard library.
  • Gradle projects are not handled; build and run them with the IDE's own Gradle actions.

Turning it off

Disable JVM Tools in the Plugin Manager. The two commands disappear, the Gradle actions come back for every project, and the template is removed from the New Project screen.
