Templates

The store page's template

The store page is made from a Pebble template. Leave Template override empty for the built-in design, or Choose a template file — such as one of the alternatives in the plugin's templates folder. Load the default template fills in the built-in one, to start from.

A template can {% extends "default" %} and replace only the parts it wants: styles, header, announcement, card, downloads or footer. Pieces and macros shared between templates go in the folder CodeOnTheGoProjects/ShareYourAppsTemplates, for {% include %} and {% import %}.

Built-in functions and filters: t("key") for text in the store's language; plural(n, "# app", "# apps"); markdown; qr("text"); bytes; and slugify.

Extra JSON

Optional settings for the whole store, as JSON, passed to the template as extra. The built-in templates use announcement, a line above the products; accent, a colour; contact, your name, email, phone and web address, shown at the foot of the page so buyers can reach you; and lang, the page's language. strings holds text for t(), by language.
