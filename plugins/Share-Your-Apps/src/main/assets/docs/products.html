Products

The list

+ Add product adds one at the end. Move up and Move down set the order buyers see. Remove takes a product out of the store at your next publish.

Name

The product's name, as buyers see it. It also names its download files, such as todo-app.apk; a second product of the same name gets todo-app-2.

Project

The Code On The Go project the product comes from. Its source can be published as a zip.

APK

The installable app buyers download, chosen from the project's builds. The picker marks unsigned builds, which buyers can't install; publishing still goes ahead, and its message notes each one.

What to publish

Publish the APK and Publish the source choose what buyers can download. A product with neither, or with no APK chosen, is left out, and the publish message says why.

Description

What buyers read about the product, in HTML.

Extra JSON

Optional details, as JSON: whatsNew, license, author and website appear on the product's card in the built-in templates. Other keys reach your own template as {{ p.extra.yourKey }}. Text from them is not checked, so use the ready-made p.websiteHref for a link, not a raw value.
