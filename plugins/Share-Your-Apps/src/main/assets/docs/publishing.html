Publishing

What Publish does

First it asks you to confirm, saying how many products the store will have, and which are left out. Cancel changes nothing.

  1. Checks that every file it needs exists.
  2. Builds a new copy of the store, beside the old one.
  3. Installs or updates Local Store Server, if needed; Android may ask you to allow it.
  4. Starts the server on the new copy, and checks every file it serves.

Until the new store is ready, buyers keep the old one — unless Local Store Server is being updated, which stops it briefly.

Its messages

Published … files verified means buyers can use it now. Left out lists products with nothing to download. Notes list things to fix that don't stop the publish, such as unsigned APKs. Couldn't publish means nothing changed: the store still serves its previous version.
