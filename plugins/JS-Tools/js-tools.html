1. Overview

JS Tools turns Code on the Go into a JavaScript and TypeScript editor with a real Node.js behind it. It bundles Node.js 24 LTS, npm, TypeScript 6, and typescript-language-server, so a project can be created, edited, run, tested, and type-checked with no network connection.

Open a folder with a package.json, tsconfig.json, or JavaScript and TypeScript files, or create one from a template. The Android build actions step aside and the JS Tools commands take their place on the editor toolbar.

TypeScript runs without a build step: Node.js removes the type annotations as it loads each .ts file, and the TypeScript compiler checks the types separately.

2. Editing

  • Syntax highlighting for .js, .mjs, .cjs, .jsx, .ts, .mts, .cts, and .tsx, from tree-sitter grammars.
  • Completion, hover, signature help, go to definition, and find references from TypeScript's language service, for JavaScript and TypeScript alike.
  • Errors as you type, the same ones Type check reports.

3. Commands

CommandWhat it doesOffline
Run appRuns the entry point (the start script, the main field, or src/index) with Node.jsYes
Run current fileRuns the JavaScript or TypeScript file open in the editorYes
Run testsRuns npm test, or Node.js's built-in node --testYes
Type checkRuns tsc --noEmit with the project's tsconfig.json or jsconfig.jsonYes
Install packagesRuns npm installNo: packages come from the npm registry

Output streams into the Build Output panel, and each command's button becomes a Cancel button while it runs.

4. Templates

TemplateWhat you get
JavaScript AppAn ES module program with a module, tests, and type checking through jsconfig.json
TypeScript AppThe same program in TypeScript with strict type checking
Node.js Web ServerA TypeScript server on node:http with JSON routes, tests, and graceful shutdown

Every template uses only Node.js's built-in modules and ships with the Node.js type declarations, so completion and tests work from the first minute without downloading anything.

5. What is bundled

  • Node.js 24 LTS and npm 11, Termux builds with the libraries they load.
  • TypeScript 6 and typescript-language-server, which power the editor and Type check.
  • The Node.js type declarations, @types/node, for the templates.

Node.js is bundled for both 64-bit and 32-bit ARM devices. On the first launch the plugin unpacks the build for the device once into its private directory, about 160 MB, and never downloads anything itself.

6. Limits

  • Programs run from the toolbar cannot read keyboard input. Pass values as arguments, or run the program from the terminal.
  • JSX and TSX files are highlighted and checked but not run, since running them needs a bundler.
  • Installing packages from npm needs a network connection.
