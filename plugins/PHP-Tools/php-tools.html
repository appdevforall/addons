1. Overview

PHP Tools turns Code on the Go into a PHP editor with a real PHP behind it. It bundles PHP 8.5, Composer, and the phpactor language server, so a project can be created, edited, run, and tested with no network connection, websites included.

Open a folder with a composer.json or PHP files, or create one from a template. The Android build actions step aside and the PHP Tools commands take their place on the editor toolbar.

A website runs on PHP's built-in web server: tap Run app and open it in a browser on the same device.

2. Editing

  • Syntax highlighting for .php and .phtml, from a tree-sitter grammar.
  • Completion, hover, signature help, go to definition, find references, and code actions from the phpactor language server.

3. Commands

CommandWhat it doesOffline
Run appRuns the start script, PHP's web server for public/, or index.phpYes
Run current fileRuns the PHP file open in the editorYes
Run testsRuns PHPUnit, the test script, or every tests/*Test.php with assertions onYes
Check syntaxRuns php -l on every PHP fileYes
Install dependenciesRuns composer installNo: packages come from Packagist

Output streams into the Build Output panel, and each command's button becomes a Cancel button while it runs.

4. Templates

TemplateWhat you get
PHP ScriptA command-line program with a class and tests
PHP Web AppA website and JSON API on the built-in web server, with routes, a stylesheet, and tests

Both templates use only PHP's built-in functions, so they run and are tested without installing anything.

5. What is bundled

  • PHP 8.5, a Termux build with its common extensions built in and the libraries it loads.
  • Composer, for projects that use packages from Packagist.
  • phpactor, the language server behind completion and navigation.

PHP is bundled for both 64-bit and 32-bit ARM devices. On the first launch the plugin unpacks the build for the device once into its private directory, and never downloads anything itself.

6. Limits

  • Programs run from the toolbar cannot read keyboard input. Pass values as arguments, or run the program from the terminal.
  • The built-in web server is for development on the device, not for serving other devices.
  • Installing packages from Packagist needs a network connection.
