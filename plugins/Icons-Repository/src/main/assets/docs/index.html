Icons Repository guide

Icons Repository adds Material icons to your project as vector drawables, from inside Code on the Go. The whole catalog is bundled with the plugin, so it works offline.

Opening the catalog

Tap Icons Repository in the side menu. The catalog opens as an editor tab with a grid of icons. The first time it opens, the icons take a moment to load.

Searching icons

Type in the search field to filter the grid by icon name, for example arrow, home or settings. Tap the clear button at the end of the field to show every icon again.

Importing an icon

Tap an icon to open the import dialog. The preview at the top shows the icon with the chosen tint.

FieldWhat it does
Icon name The drawable's resource name and file name. Use lowercase letters, digits and single underscores, starting with a letter and not ending with an underscore, for example ic_arrow_back. Java keywords such as class are not allowed. The name starts filled in from the icon's name.
Target module Which module receives the icon. All modules writes a copy into every Android module the plugin finds in the project. Pick one module to write it only there.
Color The tint. None leaves the icon untinted, so it draws in black. A theme color such as colorPrimary is written as ?attr/colorPrimary, so the icon follows your app's theme. Custom shows a field for a hex value in #RRGGBB or #AARRGGBB form.

Tap Import to write the icon. If the name or color is not valid, the field shows an error and nothing is written. Cancel closes the dialog without changing anything.

What gets written

Each import writes one file, res/drawable/<name>.xml, in the main source set of each target module. It is a 24dp vector drawable, and you use it like any other drawable, for example @drawable/ic_arrow_back in a layout or R.drawable.ic_arrow_back in code.

An existing file with the same name is replaced without asking. Pick a new name if you want to keep the old drawable.

Getting help

Long-press the search icons, an icon in the grid, or any field or button in the import dialog to see a short explanation of it.
