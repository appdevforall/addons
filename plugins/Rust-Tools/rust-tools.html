Rust Tools

Rust projects for Code on the Go, with the Rust toolchain and rust-analyzer bundled so they work offline

1. Overview

Rust Tools adds Rust as a project type in Code on the Go. While a Rust project is open, the toolbar swaps its Gradle actions for Rust ones; every other project is left untouched. The Rust toolchain ships inside the plugin, so Rust programs build, run, and test with no network connection.

Rust Tools needs the 64-bit (arm64-v8a) build of Code on the Go. The bundled toolchain is built for 64-bit ARM only.

2. Editing

  • Syntax highlighting for .rs files, from a tree-sitter grammar.
  • Completion, diagnostics, go to definition, references, and formatting from rust-analyzer.

3. Commands

CommandWhat it doesOffline
Run appRuns cargo runYes
Run current fileCompiles and runs the .rs file open in the editorYes
Format codeRuns cargo fmtYes
Run testsRuns cargo testYes

Adding a crate from crates.io needs a connection once, while cargo downloads it.

4. Templates

TemplateWhat you get
Rust StarterA minimal crate with a function and a unit test
Rust HTTP ServerA std::net server with an HTML page, a JSON route, and timeouts

Both templates use only the standard library, so they build and run without downloading anything.

5. What is bundled

  • Rust 1.99 with cargo, rustfmt, rustdoc, rust-analyzer, and the standard library source.
  • clang and lld 21 as the linker, with the Android NDK system libraries and headers.

On the first launch the plugin unpacks the toolchain once into its private directory. It takes about 600 MB on the device and needs no download.
