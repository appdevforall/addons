AI Chat

AI Chat is a plain chat with an AI model, in an editor tab. Use it to ask questions, explain an error or draft some code. Unlike the AI Core Agent, it never reads or changes your project: it only sees what you type.

What you need

  • AI Core, from the Addons Manager.
  • At least one AI backend: AI Agent Local runs a model on this device; a cloud backend sends your messages to that provider.

Using it

  • Open it from the side menu: AI Chat.
  • Pick a backend in the menu under the message box. A backend that is not ready says why, for example that no model is loaded.
  • Type a message and tap send. Tap the stop button to end a long reply.
  • Under each reply you can copy it or ask for it again. The speed shown is tokens per second.
  • Your chats are listed beside the conversation on a wide screen, and behind the menu button on a narrow one. You can rename and delete them there.

Privacy

Chats are saved only on this device, in Code on the Go's own storage, and are kept when AI Chat is updated. Delete a chat from the chat list to remove it. With AI Agent Local, nothing you type leaves the device. With a cloud backend, each message and the earlier messages of that chat go to the provider.

The chat page loads nothing from the internet. Links in a reply open in your browser only when you tap them.
