1. Overview

AI Chat adds a chat tab to Code on the Go. Ask a question, paste an error or have it draft some code, and the reply streams in as formatted Markdown with highlighted code blocks. Unlike the AI Core Agent, AI Chat never reads or changes your project: the model sees only what you type.

It runs no model itself. It needs AI Core and at least one AI backend, such as AI Agent Local to run a model on the device.

2. Using it

  • Open AI Chat from the side menu.
  • Pick a backend under the message box. One that is not ready says why.
  • Send a message; tap stop to end a long reply. Copy a reply, or ask for it again.
  • Chats are kept in a list you can rename and delete from.

3. How it works

PartWhat it does
Chat screenA React web app bundled in the addon and shown in a WebView. It is served from the addon itself and may not navigate anywhere else.
BridgeThe page's only way into the IDE: list backends, send, cancel, and load or save chats.
AI Core routerEvery message goes through AI Core's router to the backend you picked, so AI Chat gets the same routing and "not ready" messages as the Agent.

4. Privacy

Chats are saved only on the device, in Code on the Go's own storage, and are kept when the addon is updated. Delete a chat from the chat list to remove it. With AI Agent Local nothing leaves the device. With a cloud backend, each message and the earlier messages in that chat go to the provider. The chat page loads nothing from the internet; links in a reply open in the browser only when tapped.
