AI Agent Claude — Anthropic's Claude for the Agent

AI Agent Claude is a headless plugin: it has no screens of its own, only a settings pane inside AI Core. It adds the claude backend to AI Core, which routes requests from the Agent chat, Code Suggestions and Speech to Text. Install AI Core as well — without it this plugin has nothing to register with.

Setup

  • API key — required. Tap Get API Key to open the Claude Console in your browser, create a key (it starts with sk-ant-), copy it, paste it into the field and tap Save Key. The key is checked with Claude before it is saved.
  • Model — one field that is also a list: type any model id, or tap it to pick one your key can use. Typing is saved when you leave the field. The default is claude-opus-5-5, the strongest for building apps; claude-sonnet-5-5 is faster and cheaper, and claude-haiku-4-5 is fastest and cheapest.
  • Test Connection & List Models — checks the key without saving it, and fills the model list from the same reply.
The key is stored encrypted with the Android Keystore, and is sent as an x-api-key header — never in a URL, where it would leak into logs and proxies.

How the Agent uses Claude

The Agent's tools — reading, searching and editing files, building and running the app — are declared to Claude directly, so its calls arrive as structured data rather than text that has to be written exactly right. A file whose contents contain quotes or line breaks cannot break a call.

Claude thinks before it answers. That thinking is never shown, but it takes time, so a long pause before the first word of a reply is normal.

Cost

The Claude API is not free. It draws on prepaid credit in the Claude Console and is separate from a Claude.ai subscription — paying for Claude.ai does not give you API access. If you want to use the Agent without paying, use AI Agent Local to run a small model on the device, or AI Agent Gemini, which has a free tier.

Privacy

Prompts, and any file contents a plugin includes in them, are sent to Anthropic over HTTPS. Your code leaves the device.

What it does not do

  • Semantic search. Anthropic has no embeddings service, so Vector Search needs the OpenAI or Gemini backend to index a project.

Troubleshooting

  • "Claude refused your API key" — the key is wrong or revoked; re-enter it.
  • "Your Claude API credit balance is too low" — add credit in the Claude Console.
  • "Claude is overloaded or unavailable" — Claude is busy. The request was already retried twice; try again in a moment.
  • "Claude declined to answer this request" — a safety check stopped the reply. Rephrase the request, or pick a different model.
  • "Claude has no model called …" — tap Test Connection & List Models, then pick from the Model field.
  • The Claude backend never appears — AI Core isn't installed or activated; install it and restart the IDE.
