AI Agent Claude Plugin

Executive overview

AI Agent Claude adds Anthropic's Claude as an inference backend for AI Core. With a Claude API key, the Agent chat, Code Suggestions and Speech to Text can run on Claude Opus, Sonnet or Haiku, with the Agent's tools declared natively so it edits projects through structured calls.

Core functionality

  • Streaming replies over Anthropic's Messages API.
  • Multi-turn conversations and native tool calling for the Agent.
  • Stop: an in-flight reply is cancelled and its connection closed.
  • A settings pane with key entry, Keystore-encrypted storage, a model picker filled from the API, and a connection test.
  • Automatic retry when Claude is briefly overloaded or rate-limited.
  • Server-side fallback when a safety check declines a request on the models that support it.

Technical architecture

  • Raw HttpURLConnection and org.json, no SDK: the host loads plugin classes parent-first, and a bundled OkHttp would collide with the host's.
  • Pure, unit-tested units for the request shape, the event stream, tool calls, per-model parameters, retries and error classification.
  • The API key is encrypted with the IDE's KeystoreSecretStore under this plugin's own alias.

Usage

  1. Install AI Core and this plugin, then restart the IDE.
  2. Open AI Core → Agent settings and select Claude.
  3. Tap Get API Key, create a key in the Claude Console, paste it and tap Save Key.
  4. Optionally pick a model, then start a chat.

Cost

The Claude API is billed to prepaid credit, separate from a Claude.ai subscription. The free alternatives are AI Agent Local and AI Agent Gemini.

Limitations

  • No embeddings, so it cannot power Vector Search.
  • No web search yet.
