AI Code Suggestions

Requires the AI Core addon and an AI backend. This plugin holds no model of its own — it asks AI Core for every completion. Install AI Core and at least one backend, then choose it in Preferences → Configuration → Agent. Until you do, this plugin shows no completions.

Executive overview

AI Code Suggestions adds inline ghost-text code completions to the Code on the Go editor. As you type, it asks the companion AI Core plugin for a completion at the cursor and shows it as dimmed text you can accept or ignore. AI Core passes the request to the backend you selected.

It is a headless plugin — it has no screens of its own. It depends on AI Core for inference, so install AI Core first, with a backend chosen in Preferences → Configuration → Agent. Until AI Core is active the plugin stays silent and enables itself automatically once the inference service appears.

Core functionality

  • Inline ghost-text completions at the cursor via the IDE's editor service.
  • Debounced requests — waits for a short pause in typing (800 ms) before querying, to avoid a request per keystroke.
  • LRU caching — recent completions are cached (bounded) so repeated contexts don't re-query the model.
  • Language-aware prompts — the current language is passed to the model for more relevant completions.
  • Graceful degradation — no errors or noise when AI Core isn't loaded yet.

Technical architecture

ComponentRole
CodeSuggestionsPluginPlugin entry point. Registers an editor content-change listener, debounces changes, and displays/dismisses inline suggestions through IdeEditorService.
SuggestionProviderBuilds the completion prompt from the bounded up-to-cursor context and calls AI Core's LlmInferenceService; maintains the LRU cache.

Inference is delegated to AI Core over the shared service registry (SharedServices); this plugin contains no model or native code of its own.

Usage

  1. Install AI Core, an AI backend such as AI Agent Local, and AI Code Suggestions via the Plugin Manager, and restart the IDE.
  2. Choose and configure the backend in Preferences → Configuration → Agent.
  3. Start typing in the editor. After a brief pause, a completion appears as ghost text at the cursor.
  4. Accept it by tapping ↹ (the tab key) in the symbol row above the keyboard, or pressing Tab on a hardware keyboard. Keep typing, or move the cursor, to dismiss it.
Privacy: completions are generated by whichever backend you selected in AI Core. The code before the cursor is sent to that backend — it stays on the device with AI Agent Local, but is sent over HTTPS to Google, Anthropic or your OpenAI-compatible server with the Gemini, Claude or OpenAI backend. Choose the backend accordingly for sensitive code.

Key benefits

  • Backend of your choice — runs fully on-device with AI Agent Local, or uses a Gemini, Claude or OpenAI-compatible backend if you prefer.
  • Low overhead — debouncing and caching keep model calls infrequent.
  • Unobtrusive — ghost text never edits your file until you accept it, and stays silent when a suggestion isn't available.
  • Zero configuration — reuses the backend you already set up for the Agent.
