AI Code Suggestions — Guide

AI Code Suggestions offers inline ghost-text completions as you type. Inference is served by the companion AI Core plugin, so install AI Core first, with an AI backend chosen in Preferences → Configuration → Agent.

How it works

  • As you type, the plugin waits for a short pause (debounce) and then asks the AI Core model for a completion at the cursor.
  • The suggestion appears as dimmed ghost text after the cursor.
  • To accept it, tap ↹ (the tab key) in the symbol row above the keyboard, or press Tab on a hardware keyboard. Typing anything else, or moving the cursor, dismisses it.
  • Recent suggestions are cached (LRU) so repeated contexts don't re-query the model.
  • If AI Core isn't loaded yet, suggestions stay silent and enable automatically once it activates.

Privacy

To generate a completion, the code before the cursor is sent to the AI Core backend you selected. With AI Agent Local this stays on the device; with the Gemini, Claude or OpenAI backend it is sent over HTTPS to Google, Anthropic or your OpenAI-compatible server. Choose the backend accordingly for sensitive code.

Troubleshooting

  • No suggestions appear — confirm AI Core and a backend are installed and the backend is configured in Preferences → Configuration → Agent, then restart the IDE.
  • Suggestions feel slow — the debounce plus model latency add a short delay after you stop typing; local models are bounded by device speed.
