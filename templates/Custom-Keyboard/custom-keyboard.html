Custom Keyboard

A starter project for an Android keyboard in your own language

Version 1.0.0 · Author: James Turner · Template bundle: org.appdevforall.customkeyboard

Overview

Millions of people speak languages that the keyboards on their phones do not support. This template adds a Custom Keyboard project to Code on the Go's New Project screen. It creates a complete Android keyboard that builds and runs on the device, with English and Hindi layouts to start from.

Each language is a JSON file you edit. To support a new language, write its layout; the Kotlin code does not change.

What the keyboard does

  • Letter, shift and symbols pages, with caps lock on a double-tap of shift.
  • Long-press a key for its alternatives, such as accented letters or nukta forms.
  • Keys that type several code points, as conjuncts such as क्ष need.
  • An enter key that shows what it will do: Send, Search, Go, Next or Done.
  • Capitals at the start of a sentence, where the layout and the text field want them.
  • Every key readable by TalkBack. Keys grow with the system font size.
  • A setup screen that walks the user through turning the keyboard on and choosing it.

Usage

Install

  1. Download custom-keyboard.cgt from the add-on gallery.
  2. In Code on the Go, open Preferences → Add-ons Manager and switch to the Templates tab.
  3. Tap +, browse to the downloaded .cgt and select it, then tap Install.

Create and try a keyboard

  1. Open New Project, pick Custom Keyboard, enter an app name and package name, and tap Create.
  2. Run the project. The setup screen opens.
  3. Tap Open keyboard settings and switch the keyboard on, then tap Choose keyboard and pick it.
  4. Type in the Try it field. The key beside ?123 changes language.

Add a language

Copy app/src/main/assets/layouts/01-english.json, edit the rows, and run again. The project's README describes every field.

Limitations

  • No word prediction, dictionary or swipe typing. This is a starting point, not a finished product.
  • The keyboard can type any Unicode text, but other apps draw it with the system font. A script with no font on the device shows as boxes there.
